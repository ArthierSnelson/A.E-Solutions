# AE Solutions

First production-oriented website build for AE Solutions.

## Positioning

AE Solutions is structured around five capabilities:
- Website Design & Development
- App Development
- Business Automation
- Lead Generation
- Investments & Ventures

The site deliberately avoids fabricated testimonials, client results, team size, revenue claims or investment performance.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Routes

- `/`
- `/services/web`
- `/services/apps`
- `/services/automation`
- `/services/lead-generation`
- `/ventures`
- `/about`
- `/contact`

The enquiry form is intentionally in demo mode until a real email/CRM endpoint is selected.
